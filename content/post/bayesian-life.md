一条检测准确率 99% 的技术，告诉你「阳性」。你得病的概率是多少？

直觉会说 99%。正确答案可能只有 2%。这两者之间的差距，是贝叶斯定理要处理的问题。

## 1. 公式本身没什么神秘

$$P(H|E) = \frac{P(E|H)\,P(H)}{P(E)}$$

符号读法：

- $H$ 是假设（Hypothesis），比如「我得了这种病」；
- $E$ 是证据（Evidence），比如「检测结果是阳性」；
- $P(H|E)$ 是**已知证据后**假设成立的概率，叫后验；
- $P(H)$ 是**看到证据之前**假设成立的概率，叫先验；
- $P(E|H)$ 是假设成立时出现这个证据的概率，叫似然。

公式说的是：**后验正比于先验乘似然**。分母 $P(E)$ 只是归一化用的常数，把右边缩放成一个合法的概率。

真正有信息量的部分在分子上。先验 $P(H)$ 起作用的方式，是很多人第一次接触时会觉得反直觉的地方。

## 2. 一个具体例子：99% 准确的检测

假设某种病在人群中的患病率是 0.1%，也就是 1000 个人里有 1 个。检测的灵敏度 99%（有病的人里 99% 测出阳性），特异度 99%（没病的人里 99% 测出阴性，即假阳性率 1%）。

现在随机抽一个人，检测阳性。他真得病的概率是多少？

先把 10 万人摊开来算，比套公式直观：

| | 有病 | 没病 | 合计 |
|---|---|---|---|
| 检测阳性 | 99 | 999 | 1098 |
| 检测阴性 | 1 | 98901 | 98902 |
| 合计 | 100 | 99000 | 100000 |

10 万人里 100 个病人，其中 99 个被测出来。99900 个健康人里，1% 误报，也就是 999 个假阳性。

所以所有阳性的人一共 99 + 999 = 1098 个，其中真病人只有 99 个：

$$P(\text{有病} \mid \text{阳性}) = \frac{99}{1098} \approx 9\%$$

不是 99%，是 9%。

用公式验算一遍。$P(H) = 0.001$，$P(E|H) = 0.99$，所以分子是 $0.00099$。分母要算全概率：

$$P(E) = 0.99 \times 0.001 + 0.01 \times 0.999 = 0.00099 + 0.00999 = 0.01098$$

$0.00099 / 0.01098 \approx 0.0902$，和表格一致。

这个例子的关键不在计算，在于**分母被健康人撑大了**。病人基数太小，即使误报率只有 1%，误报的绝对数量也远超真阳性。这叫基础率谬误：人倾向于盯着检测本身的准确率，忽略了这个病本来有多罕见。

> [!IMPORTANT]
> 任何一个「准确率 99%」的检测，如果用在患病率 0.1% 的人群里，阳性结果的可信度都只有百分之十几。所以医学上阳性之后通常要复查，复查时先验已经变成 9%，同样的检测就能给出 90% 以上的后验。

## 3. 复查为什么有效

延续上面的例子。第一次阳性后，这个人的后验概率是 9%。现在他再做一次同样的检测，又阳性。

这次先验是 9%，不是 0.1% 了：

$$P(E) = 0.99 \times 0.09 + 0.01 \times 0.91 = 0.0891 + 0.0091 = 0.0982$$

$$P(H|E) = \frac{0.99 \times 0.09}{0.0982} \approx 0.907$$

两次阳性，后验从 9% 升到 91%。第三次会到 99.9% 以上。

这解释了为什么医院的流程总是「初筛异常 → 复查 → 确诊」，而不是一次检测定论。**每一次检测都在用上一次的结果当前验**，信息是这样一层层累积起来的。

同一个道理反过来用，就是筛查策略的设计依据。低患病率人群做普筛，假阳性会淹没真阳性，医疗系统承受不了；所以很多癌症筛查有年龄门槛，那不是歧视，是先验决定的。

## 4. 垃圾邮件过滤器：朴素贝叶斯

贝叶斯最广为人知的工程应用是垃圾邮件过滤。思路很直接：一封邮件是垃圾邮件的概率，取决于它里面出现了哪些词。

问题在于直接算 $P(\text{垃圾} \mid \text{包含「发票」「中奖」「点击领取」})$ 需要知道这三个词同时出现的所有组合，样本根本不够。

「朴素」两个字的含义就在这里：**假设各个词之间相互独立**。这个假设明显不成立（「点击」和「领取」经常一起出现），但工程上它好用得惊人。

独立假设让联合概率可以拆成连乘：

$$P(w_1, w_2, \dots, w_n \mid \text{垃圾}) = \prod_{i} P(w_i \mid \text{垃圾})$$

每个 $P(w_i \mid \text{垃圾})$ 都能从标注过的邮件里直接数出来：垃圾邮件里「发票」出现的次数，除以垃圾邮件的总词数。

判定时比较两个后验的比值，分母 $P(E)$ 相同，可以直接约掉：

$$\frac{P(\text{垃圾} \mid E)}{P(\text{正常} \mid E)} = \frac{P(E \mid \text{垃圾})\,P(\text{垃圾})}{P(E \mid \text{正常})\,P(\text{正常})}$$

比值超过阈值就判为垃圾。$P(\text{垃圾})$ 这个先验也不可少：如果你的邮箱里垃圾邮件本来就占八成，那一条模棱两可的邮件更应该被判成垃圾。

实际实现里有个必须处理的细节：**某个词如果在训练集里从没出现过，它的概率是 0，连乘下来整个结果归零**。解决办法是给每个词的出现次数加 1（拉普拉斯平滑），这样没见过的词得到一个很小的非零概率，不会一票否决全部证据。

## 5. 导航软件的到达时间是怎么算的

手机导航说「预计 18:40 到达」，这个数字不是查表得来的，是贝叶斯更新的结果。

模型对每一段路都有一个先验：这条路在周三下午五点通常要开 12 分钟（历史数据统计出来的）。出发后开始收到证据：GPS 显示你实际走了 200 米用时 40 秒，折算下来比先验慢。

于是更新：这一段的后验时间分布整体右移。逐段累加，全程的预计时间就变了。

这也是为什么刚出发时预计到达时间经常剧烈跳动，开了一段之后反而稳定：**证据少的时候先验占主导，证据多了先验的影响就被冲淡**。这个「先验权重随证据量衰减」的行为，是贝叶斯的自然结果，不需要额外设计规则。

同样的机制在做推荐系统（你的点击是证据，你的兴趣是先验）、在 A/B 测试（实验结果不断更新两个版本的转化率分布）、在强化学习（对每个动作的收益估计做更新）。

## 6. 四个常见错误

**把 $P(E|H)$ 和 $P(H|E)$ 搞混。** 这是最常见的错误，名字叫检察官谬误。法庭上常出现这样的论证：「凶手匹配这个 DNA 特征的概率是百万分之一，所以被告无罪的概率是百万分之一。」错了。百万分之一是 $P(\text{匹配} \mid \text{无辜})$，而法庭要的是 $P(\text{无辜} \mid \text{匹配})$。在一个千万人口的城市里，即使无辜，也有十个人会匹配上这个特征。

**忽略先验。** 就是第 2 节那个例子。只报灵敏度和特异度、不报患病率的检测宣传，基本都在误导。

**先验设成 0 或 1。** 数学上，如果先验给某个假设 0 概率，那么无论来多少证据，后验都还是 0——乘法里有个因子是零，结果永远是零。这叫克伦威尔规则。实践中的含义是：不要给任何假设留绝对的零概率，否则你永远学不到东西。

**重复使用同一份证据。** 如果两次「检测」读的是同一批数据，那么第二次不构成独立证据，把它当成新的 $E$ 再更新一遍，等于把同一个信息算了两遍，后验会过度自信。这在数据分析里很常见：同一批样本上做了多次检验，每次都当作独立发现。

## 7. 想动手算的话

```python
from fractions import Fraction


def bayes(prior, sensitivity, specificity):
    """返回检测阳性时真正有病的概率。

    prior:       先验患病率
    sensitivity: 灵敏度 P(阳性|有病)
    specificity: 特异度 P(阴性|没病)
    """
    p_pos_given_sick = sensitivity
    p_pos_given_healthy = 1 - specificity

    numerator = p_pos_given_sick * prior
    denominator = numerator + p_pos_given_healthy * (1 - prior)
    return numerator / denominator


# 第 2 节的例子
print(bayes(0.001, 0.99, 0.99))   # 0.0902...

# 复查一次：把上次的后验当新的先验
p1 = bayes(0.001, 0.99, 0.99)
p2 = bayes(p1, 0.99, 0.99)
print(p2)                          # 0.907...

# 换成高患病率人群（比如有家族史，先验 10%）
print(bayes(0.1, 0.99, 0.99))      # 0.916...
```

同一套检测，只因为人群的先验不同，阳性结果的意义从 9% 变到 92%。这就是为什么同样的化验单，医生要看你的年龄、家族史、既往病史——那些都是先验。

如果把上面的 `bayes` 函数改成一个循环，让每次的输出当下一次的输入，你就得到了一个最简单的贝叶斯更新器。垃圾邮件过滤器、导航软件、推荐系统，内核都是这个循环，区别只在于先验和似然怎么估。
