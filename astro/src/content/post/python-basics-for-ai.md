上一篇 [第 1 篇](/post/python-zero-setup/) 把环境装好了，你跑出过 `print("你好，世界")`。

那行代码除了让你兴奋三十秒，没什么用。这一篇我们要做一个**真的有用**的东西：一个 BMI 计算器。你告诉它身高体重，它告诉你胖不胖。

做完它，你就会用上 Python 入门阶段最重要的五样东西：数据、变量、类型、输入输出、运算。而且它们不是按语法书顺序排的，是**为了解决这个问题才被引入的**——这样你才知道每个东西到底是干什么用的。

## 1. 先看看我们要做什么

最终成品长这样，你输入身高体重，它给出结果：

```text
请输入你的身高（米）：1.75
请输入你的体重（公斤）：70
你的 BMI 是 22.86
体型评价：正常 🎉
```

看着简单，但要做出来，得依次解决四个问题：

1. **数字从哪来？**——用户要能输进来（本篇第 3、4 节）
2. **输入后存哪？**——需要变量（第 3 节）
3. **怎么算 BMI？**——需要运算（第 5、6 节）
4. **怎么输出好看的句子？**——需要字符串格式化（第 4 节）

我们一个一个来，每学一样就往程序里加一块。学完，程序也就写完了。

## 2. 数据在代码里长什么样：字面量

在写程序之前，先看一个最朴素的问题：代码里要怎么表达「70」这个数字、或者「张三」这个名字？

答案就是你直接把它写出来。**直接写在代码里的值，叫字面量（literal）**——字面意思：字面上就是这个值。

```python
42              # 整数
1.75            # 小数
"张三"          # 一段文字
True            # 真
None            # 什么都没有
```

Python 里常见的字面量就这五类，先混个脸熟：

| 你写的 | 类型名 | 人话解释 |
|---|---|---|
| `42`、`-5`、`0` | `int`（整数） | 没有小数点的数 |
| `1.75`、`3.14` | `float`（浮点数） | 带小数点的数 |
| `"张三"` | `str`（字符串） | 一段文字，用引号包起来 |
| `True` / `False` | `bool`（布尔） | 只有真和假两个值 |
| `None` | `NoneType` | 表示「空」，还没有值 |

三处新手常出错的地方：

- **布尔值的首字母必须大写**：`True`、`False`。写成 `true` 会报 `NameError`，因为 Python 不认识小写的 `true`。
- **`None` 不是 0，也不是空字符串**。它是「这里暂时没有东西」的专用标记，后面第 6 篇讲函数默认值时还会遇到它。
- **引号必须是英文引号**。中文引号 `“张三”` 是最隐蔽的错误之一，因为看上去几乎一样。

> [!TIP]
> 判断自己有没有写成中文标点，有个笨但有效的办法：把输入法切到英文，重新敲一遍。新手期 80% 的「代码看着没错却跑不了」，都是中文标点干的。

## 3. 给数据起名字：变量

现在有了数字，但光写 `1.75` 没用——程序得记住它，后面还要拿它算 BMI。这就需要**变量**。

变量是**给数据起的名字**。语法就一个等号：

```python
height = 1.75
weight = 70
```

读作「把 1.75 存进名叫 height 的盒子里」。之后你在任何地方写 `height`，Python 都会拿出 `1.75` 来用。

> [!WARNING]
> 这里的 `=` 不是数学里的「等于」，是**赋值**。`height = 1.75` 的意思是「把右边的值放进左边的盒子」，方向不能反。`1.75 = height` 会直接报错。

### 3.1 三条必须记住的规则

**规则一：先赋值，再使用。**

```python
print(age)      # 报错 NameError: name 'age' is not defined
age = 18
```

Python 从上往下执行，跑到 `print(age)` 时，`age` 这个盒子还不存在，所以它不认识。这和第 1 篇说过的「一行行执行」是同一件事。

**规则二：一个变量同一时刻只能装一个值，后来者覆盖。**

```python
score = 60
score = 95
print(score)    # 95，60 已经没了
```

**规则三：可以一行赋多个值。**

```python
a, b = 1, 2
a, b = b, a     # 交换两个变量，Python 特有写法
print(a, b)     # 2 1
```

最后这个交换很有意思。别的语言要借一个临时变量倒手，Python 一行搞定。原理是等号右边先整体算完，再分别装进左边。

### 3.2 变量名怎么起

变量名起得好不好，直接决定你三个月后还看不看得懂自己的代码。

**硬规则**（违反直接报错）：

1. 只能用字母、数字、下划线；
2. 不能以数字开头——`name1` 行，`1name` 不行；
3. 不能用 Python 的关键字，比如 `if`、`for`、`True`、`None`；
4. 区分大小写——`age`、`Age`、`AGE` 是三个不同的变量。

**软规范**（不报错，但会让你显得专业）：

- 见名知意：`user_weight` 胜过 `w`；
- 多个单词用下划线连：`total_price`，这叫蛇形命名法（snake_case）；
- 变量名全小写，常量才全大写。

> [!NOTE]
> 这些规范来自 Python 官方的 PEP 8 风格指南：<https://peps.python.org/pep-0008/>。现在不用背，写多了自然会。

### 3.3 Python 的一个特点：变量本身没有类型

这一点和 Java、C 很不一样，值得单独说：

```python
num = 10
print(type(num))    # <class 'int'>

num = "Python"
print(type(num))    # <class 'str'>
```

同一个变量，先装整数，后装字符串，完全不报错。这叫**动态类型**——类型跟着**值**走，不跟着变量走。所以你写 `type(x)` 查的是「x 现在装的东西是什么类型」，不是「x 这个变量被声明成什么类型」。

## 4. 让程序开口说话，也让程序听得见

到这一步，我们的程序还是死的：身高体重写死在代码里。真正的计算器得让用户输进来。

### 4.1 输出：print()

`print()` 你应该已经熟了，但有几个用法值得一开始就掌握：

```python
print("你好")              # 你好
print("BMI", 22.86)       # BMI 22.86  ← 逗号分隔，自动加空格
print("a", "b", sep="-")  # a-b        ← 自定义分隔符
```

### 4.2 输入：input()

```python
name = input("请输入你的名字：")
print(f"你好，{name}")
```

`input()` 会先显示括号里的提示语，然后**停住等你打字**，你按下回车，它就把你输入的内容返回。

这里有个**新手第一大坑**：

> [!WARNING]
> `input()` 拿到的**永远是字符串**，哪怕你输入的是 `70`。

```python
age = input("年龄：")      # 你输入 18
print(type(age))          # <class 'str'>，不是 int！
print(age + 1)            # 报错 TypeError
```

`"18" + 1` 在 Python 看来是「一段文字加一个数字」，它不知道该干嘛。所以必须手动转换：

```python
age = int(input("年龄："))   # 用 int() 把字符串转成整数
print(age + 1)              # 19
```

这是几乎所有 Python 新手的第一课。记住它，能省你半小时的困惑。

### 4.3 类型转换四件套

| 函数 | 作用 | 例子 |
|---|---|---|
| `int()` | 转成整数 | `int("18")` → `18` |
| `float()` | 转成小数 | `float("1.75")` → `1.75` |
| `str()` | 转成字符串 | `str(18)` → `"18"` |
| `bool()` | 转成布尔 | `bool(0)` → `False` |

转换失败会报 `ValueError`：

```text
ValueError: invalid literal for int() with base 10: 'abc'
```

意思是「`abc` 没法变成整数」。这个报错你以后会见到无数次，通常是用户输错了东西——第 9 篇会教你用 `try/except` 优雅地接住它。

### 4.4 字符串格式化：f-string

现在我们有名字、有数字，想拼成一句话。最古老的写法是用 `+` 拼：

```python
name = "张三"
age = 18
message = "我叫" + name + "，今年" + str(age) + "岁"
```

能用，但很丑，还得记得 `str()`。

现代 Python 一律用 **f-string**：在引号前加个 `f`，然后用花括号把变量塞进去。

```python
name = "张三"
age = 18
print(f"我叫{name}，今年{age}岁")
```

输出：`我叫张三，今年18岁`。

花括号里不光能放变量，还能放算式、调用函数：

```python
price, count = 9, 3
print(f"总价：{price * count}")     # 总价：27
print(f"平均分：{86.333:.2f}")       # 平均分：86.33  ← .2f 表示保留两位小数
```

`:.2f` 这个写法先记住，算 BMI 马上要用。

## 5. 让程序会算数：算术运算符

Python 的算术运算符和小学数学基本一致，但有两个必须搞清楚：

| 运算符 | 含义 | 例子 | 结果 |
|---|---|---|---|
| `+` `-` `*` | 加减乘 | `3 * 8` | `24` |
| `/` | 除法 | `10 / 5` | `2.0`（注意是小数！） |
| `//` | 整除 | `10 // 3` | `3`（只要整数部分） |
| `%` | 取余 | `10 % 3` | `1` |
| `**` | 幂 | `10 ** 3` | `1000` |

**易混点一：`/` 的结果永远是浮点数。**

```python
print(10 / 5)     # 2.0，不是 2
print(10 // 5)    # 2
```

**易混点二：`%` 取余，用来判断「能不能整除」。**

```python
print(10 % 2 == 0)   # True，能整除就是偶数
print(7 % 2 == 0)    # False，奇数
```

这个技巧在第 3 篇写循环时会反复出现。

### 5.1 一个反直觉的现象：0.1 + 0.2

```python
print(0.1 + 0.2)          # 0.30000000000000004
print(0.1 + 0.2 == 0.3)   # False
```

不是 Python 有 bug。计算机用二进制存小数，而 0.1 在二进制里是无限循环小数，只能存一个近似值，加起来的误差就露出来了。**所有编程语言都这样。**

所以：**永远不要用 `==` 判断两个小数是否相等**。要判断，就看它们的差是不是足够小：

```python
abs((0.1 + 0.2) - 0.3) < 1e-9    # True
```

涉及金额计算时，用 `decimal` 模块或者干脆换算成「分」用整数算。这个坑现在知道就行，遇到了能想起来。

## 6. 赋值、比较、逻辑：三类运算符

### 6.1 复合赋值：在旧值上更新

```python
score = 60
score += 10      # 等价于 score = score + 10
print(score)     # 70
```

`+=` `-=` `*=` `/=` 是最常用的四个，第 3 篇写计数器时每天都要用。

### 6.2 比较运算符：结果是 True 或 False

```python
print(10 == 10)   # True    等于
print(10 != 9)    # True    不等于
print(10 > 20)    # False
print(10 >= 10)   # True
```

> [!WARNING]
> `=` 是赋值，`==` 是判断相等。这是新手最容易混的一对符号。看到 `if age = 18` 报错，就是这个原因。

### 6.3 逻辑运算符：and / or / not

- `and`：两个都为真才为真（登录时账号**且**密码都对）；
- `or`：有一个为真就为真（扫码、密码、短信**任一**方式登录）；
- `not`：取反。

```python
username_ok = True
password_ok = False
print(username_ok and password_ok)   # False，登录失败

print(not password_ok)               # True
```

Python 还支持数学式的连续比较，这个别的语言没有：

```python
num = 15
if 10 <= num <= 20:      # 等价于 10 <= num and num <= 20
    print("在范围内")
```

## 7. 动手：把 BMI 计算器写出来

材料齐了。现在组装。

### 7.1 第一版：能算就行

```python
height = float(input("请输入你的身高（米）："))
weight = float(input("请输入你的体重（公斤）："))

bmi = weight / (height ** 2)

print(f"你的 BMI 是 {bmi:.2f}")
```

跑一下：

```bash
python bmi.py
```

输入 `1.75` 和 `70`，你会看到 `你的 BMI 是 22.86`。

**这一步你已经用上了**：变量（`height`、`weight`、`bmi`）、类型转换（`float()`）、算术运算符（`/`、`**`）、f-string（`:.2f`）。一篇基础语法的大半内容，在一个真实需求里全用完了。

### 7.2 第二版：加一句评价

光有数字没意义，用户想知道「22.86 到底算不算胖」。这需要判断，而判断需要 `if`——那是第 3 篇的内容。不过它太简单了，我们提前用一下：

```python
height = float(input("请输入你的身高（米）："))
weight = float(input("请输入你的体重（公斤）："))

bmi = weight / (height ** 2)
print(f"你的 BMI 是 {bmi:.2f}")

if bmi < 18.5:
    print("体型评价：偏瘦")
elif bmi < 24:
    print("体型评价：正常 🎉")
elif bmi < 28:
    print("体型评价：偏胖")
else:
    print("体型评价：肥胖")
```

这里的规则是中国的 BMI 标准（和国际标准略有不同，不必纠结）。

`if` 这段现在看不懂没关系，第 3 篇会把它拆开讲透。你只需要先感受一件事：**代码是可以一块块往上叠的**。第一版能跑，第二版加功能，第三版再加——真实的软件就是这么长出来的。

### 7.3 一个必然会遇到的崩溃

故意试试：身高那里输入 `abc`。

```text
ValueError: could not convert string to float: 'abc'
```

程序直接死了。这就是「用户不按套路输入」的后果。第 9 篇会用 `try/except` 给它套上安全网，现在先记住这个报错长什么样。

## 8. 新手最常踩的 8 个坑

1. **中文标点**——`,`、`"`、`()`、`：` 必须全英文；
2. **`input()` 结果直接算数**——它是字符串，要先 `float()` 或 `int()`；
3. **`=` 和 `==` 混用**——赋值用 `=`，比较用 `==`；
4. **变量先用后定义**——Python 从上往下执行，不会预知你要用什么；
5. **`/` 和 `//` 分不清**——前者得小数，后者得整数；
6. **`True` 写成 `true`**——首字母必须大写；
7. **用 `==` 比小数**——浮点数有精度误差，改用差值判断；
8. **变量名叫 `a`、`b`、`c`**——省事三天，痛苦三个月。

## 9. 课后小项目

三个难度递增的练习，**至少做完第一个再往下读**。

**练习一：零钱计算器（必做）**

去超市买了几样东西，输入每样的价格和数量，输出总价。如果总价超过 100，输出「已打 9 折」并给出折后价。

提示：需要 `float(input())` 三次、乘法、加法、一个 `if`（照抄 BMI 那段的写法即可）。

**练习二：时间换算器**

输入一个秒数（比如 `3725`），输出「1 小时 2 分 5 秒」。

提示：`//` 和 `%` 的组合。`3725 // 3600` 得小时，`3725 % 3600` 出剩余秒数，再继续拆。

**练习三：汇率换算**

输入人民币金额和当日汇率（比如 7.18），输出换算后的美元金额，保留两位小数。

提示：注意 `:.2f`，也注意这个场景**不要**用 `==` 判断金额。

## 10. 本篇小结

看完这篇，你应该能回答：

1. **字面量和变量什么区别？** 字面量是数据本身（`70`），变量是给数据起的名字（`weight = 70`）。
2. **`type()` 查的是什么？** 查的是变量**当前装的那个值**的类型，不是变量的类型。
3. **为什么 `input()` 后面总要加 `float()` 或 `int()`？** 因为 `input()` 永远返回字符串，字符串不能直接参与数学运算。
4. **`/` 和 `//` 的区别？** `/` 得浮点数，`//` 只保留整数部分。
5. **`0.1 + 0.2` 为什么不等于 `0.3`？** 二进制表示小数的固有误差，所有语言都有。
