如果你从没写过一行代码，这一篇是起点。

先给你吃颗定心丸：编程不是数学竞赛，不需要你聪明，也不需要你背下来什么。它更像学做菜——看一遍菜谱、亲手切一次、炒糊两次，就会了。你唯一需要准备的，是一台电脑和二十分钟不被打扰的时间。

这篇文章只做一件事：**让你亲手跑出第一个程序**。跑通了，你就正式上路了；后面七篇讲的语法，都是在这个基础上往外长。

## 1. 先说清楚：Python 是什么

电脑很笨，它只会做「加法」和「比较」这两类最底层的操作，快得惊人，但完全不会自己思考。**编程，就是你用电脑听得懂的话，把「要做什么」一条条写下来。**

而 Python 就是这套「话」里最好学的一种。看两段同样的意思，别的语言写起来是这样：

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("你好，世界");
    }
}
```

Python 是这样：

```python
print("你好，世界")
```

一行，还是英文单词加引号，接近人话。这就是为什么全世界的入门课、数据分析、人工智能，都首选 Python——它把「表达想法」和「写代码」之间的距离压到了最短。

> [!NOTE]
> 「人工智能」「大模型」这类听起来高大上的东西，底层大量用 Python 写成。这也是本专栏最后要走向的方向：先用 Python 打好基础，再去看 AI 是怎么跑起来的。

## 2. 安装 Python：只点三下鼠标

很多人卡在这一步就放弃了，其实它比装个微信还简单。

### 2.1 下载安装包

打开浏览器，访问 Python 官网：

<https://www.python.org/downloads/>

页面中间会有一个黄色大按钮，写着 **Download Python 3.x.x**，直接点它。（`3.x.x` 是版本号，数字会随更新变化，不用纠结具体是几。）

> [!WARNING]
> 不要从第三方「软件下载站」下 Python。那些站点会把安装包重新打包，捆绑一堆东西。只认 `python.org` 这一个域名。

### 2.2 安装时最关键的一个勾

双击下载好的安装包，出现的第一个界面里，**最下面有个复选框，写着 `Add python.exe to PATH`，一定要勾上。**

这一步决定你之后能不能在命令行里用 `python` 这个命令。漏勾了不是不能救，但要重新装一遍，很烦。勾上，然后点 `Install Now`。

等进度条走完，看到 `Setup was successful`，关掉窗口。

### 2.3 验证装好了没有

按 `Win + R`，输入 `cmd`，回车，会弹出一个黑框——这叫**命令行**（也叫终端）。它是你和电脑直接对话的窗口，以后写程序经常要在这里跑命令。

在黑框里输入这一行，回车：

```bash
python --version
```

如果出来类似 `Python 3.13.11` 这样的一行字，恭喜，装好了。

如果提示 `'python' 不是内部或外部命令`，说明第 2.2 步的勾漏了。卸掉重装，记得勾上。

> [!NOTE]
> Mac 用户：macOS 自带了 Python，但版本往往很旧。建议同样去官网下载安装包，或者用 `brew install python`。装完在「终端」里敲 `python3 --version`（注意是 `python3`，不是 `python`）。

## 3. 先别急着装编辑器，用自带的玩一下

新手最容易犯的错，是先花两小时挑编辑器、配主题、装插件，然后累了，关掉，再也不打开。**先用最简单的工具跑通一次，再升级装备。**

在命令行里输入 `python`（Mac 是 `python3`），回车。你会发现提示符变成了 `>>>`，这叫**交互模式**——你敲一行，它立刻执行一行。

试试输入：

```python
print("你好，世界")
```

按回车。屏幕上会立刻出现 `你好，世界`。

再试试算数：

```python
2 + 3 * 4
```

回车，它直接给你 `14`。

这就是程序最小的一次运行。你已经写过程序了。要退出交互模式，输入 `exit()` 回车。

## 4. 换正经工具：写第一个 .py 文件

交互模式只能玩一行丢一行，没法保存。真正的程序写在**文件**里。

### 4.1 装什么编辑器

推荐 **VS Code**，免费、轻量、中文完善：

<https://code.visualstudio.com/>

下载安装，一路下一步即可。装完打开，界面左边是一排图标，中间是一大片空白——别慌，它就是一个高级记事本。

装完做一件事：左侧图标栏点最下面那个「扩展」（四个方块，其中一个飞出去的样子），搜索 `Python`，找到微软官方发布的那个（作者标着 Microsoft，几千万下载量），点 `Install`。

### 4.2 建文件夹、建文件

1. 在电脑上新建一个文件夹，比如 `D:\python学习`，**路径里不要有中文以外的特殊符号，也不要有空格**（Windows 用户尤其注意，路径有空格以后会遇到各种莫名其妙的错）。
2. 打开 VS Code，菜单 `文件 → 打开文件夹`，选中刚才那个文件夹。
3. 左边会出现文件夹名。鼠标悬停在名字上，点「新建文件」图标，输入文件名 `hello.py`。

> [!TIP]
> `.py` 这个后缀就是告诉电脑「我是个 Python 文件」。就像 `.docx` 是 Word 文档、`.jpg` 是图片。写代码时忘了加 `.py`，编辑器就不知道该怎么给你上色。

### 4.3 写下第一段真正能保存的代码

在 `hello.py` 里输入：

```python
print("你好，世界")
print("我叫 Python，从今天起是你的工具")
print("1 + 1 =", 1 + 1)
```

保存（`Ctrl + S`）。注意左下角，如果有个圆点，说明没保存。

### 4.4 跑起来

在 VS Code 里按 `` Ctrl + ` ``（键盘左上角 Esc 下面那个键），打开终端面板。然后输入：

```bash
python hello.py
```

按回车。下方会输出：

```text
你好，世界
我叫 Python，从今天起是你的工具
1 + 1 = 2
```

**这就是你人生第一个亲手写、亲手跑起来的程序。** 它没什么用，但它是真的——从这一秒起，你不再只是「看别人写代码」的人了。

一个新手常见卡点：如果提示 `can't open file 'hello.py'`，说明终端当前所在的目录不是你建文件的那个目录。解决办法是在终端里先 `cd` 过去：

```bash
cd D:\python学习
python hello.py
```

或者在 VS Code 里直接右键文件，选 `在集成终端中运行 Python 文件`。

## 5. 程序是怎么被执行的：一个够用的心智模型

现在回头看刚才那三行，建立第一个正确的直觉：

```python
print("你好，世界")     # 第 1 行
print("我叫 Python")    # 第 2 行
print("1 + 1 =", 2)     # 第 3 行
```

电脑是**从上往下一行一行**执行的，不跳步，不猜你的心思。第 1 行跑完才跑第 2 行。这一点看着平淡，但它解释了后面 90% 的「为什么结果是这个」——只要你的结果和预期不符，就回到代码里，按顺序一行行读，问自己「执行到这一行时，电脑手里有什么」。

`print` 这个词的意思是「打印」，但在编程里它其实是「**把东西显示到屏幕上**」，不一定真的打印到纸上。

括号里的内容是**你要显示的东西**。引号里的文字原样输出，引号外的算式会先算出结果再输出——所以 `1 + 1` 显示的是 `2`，而不是 `1 + 1`。

## 6. 第一天会遇到的五个报错

报错不是你笨，是电脑在告诉你「我没听懂」。读懂报错，是编程里最值钱的技能之一。新手第一天八成会撞上这五个：

**1. `SyntaxError: invalid syntax`（语法错误）**

最常见的原因：**用了中文标点**。

```text
print（"你好"）    ← 括号是中文的，报错
print("你好")      ← 正确
```

还有个原因是忘了写另一半引号或括号。电脑看不懂半句话。

**2. `NameError: name 'xxx' is not defined`（名字没定义）**

你用了 `print(age)`，但从来没写过 `age = 18`。电脑不认识 `age` 这个名字。记住：**变量要先赋值，才能用。**

**3. 中文乱码，或者输出一堆看不懂的符号**

在 Windows 的老版本里，终端默认编码可能不是 UTF-8。现在的新版本一般没这问题；万一遇到，把终端换成 Windows Terminal，或者在文件开头加一行：

```python
# -*- coding: utf-8 -*-
```

**4. `IndentationError: unexpected indent`（缩进错误）**

Python 用缩进（行首的空格）表示「这几行属于一起」。如果你某行前面莫名其妙多了空格，它会报错。新手常见于从网页复制代码，带进了看不见的空白。

**5. 程序一闪而过，什么都没看到**

双击 `.py` 文件运行，窗口可能瞬间关闭。正确做法是在命令行里 `python 文件名.py` 运行，这样窗口会留着显示结果。

> [!TIP]
> 遇到报错，先看**最后一行的最后一段**。那一行才是真正的错误类型和描述，上面一堆 `Traceback` 只是告诉你错误出在哪个文件的哪一行。新手常犯的错是从上往下读报错，读到一半就慌了。

## 7. 装好之后，怎么用这个专栏

专栏按 `weight` 顺序排，从第 1 篇一路读到最后：

| 篇目 | 你会得到什么 |
|---|---|
| 第 1 篇（本篇） | 环境能跑，知道程序是什么 |
| 第 2 篇 | 数据怎么存、怎么算、怎么输入输出 |
| 第 3 篇 | 让你的程序会判断、会重复、会复用 |

**怎么读效率最高**：每一篇的代码都亲手敲一遍，不要复制粘贴。复制粘贴省下的那点时间，会在你「看着好像懂、一写就错」的时候加倍还回来。敲错了、报错了、改对了，这个过程本身就是在学。

> [!IMPORTANT]
> 不要试图一次读完。一天一篇，每篇敲完代码、做完文末的小项目就停。学编程的速度不由「读了多少」决定，由「独立写出来多少」决定。

## 8. 本篇小结

1. Python 是一门接近自然语言的编程语言，适合零基础入门，也是 AI 领域的主力语言；
2. 安装时**务必勾选 `Add python.exe to PATH`**，装完用 `python --version` 验证；
3. 程序写在 `.py` 文件里，用 `python 文件名.py` 运行；
4. 电脑从上到下一行行执行代码，`print(...)` 把括号里的东西显示到屏幕上；
5. 报错先看最后一行的错误类型，中文标点和「变量没定义」是新手头号杀手。
