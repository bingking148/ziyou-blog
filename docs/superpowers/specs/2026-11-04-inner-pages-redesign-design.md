# 内页重构：搜索目录卡 · 关于档案卷宗 · 友链名片与灯

日期：2026-11-04 ｜ 状态：已获用户批准方向，待文档审阅

## 背景与目标

首页已完成「朱砂切口」三幕与冰蓝杂志第二幕，内页仍是常规 PageHero + 列表，与首页气质脱节。本次重构搜索、关于、友链三页，目标是：

- 与全站统一风格，但**不复制第二幕的模块**——首页的海报开场只属于首页；
- 三页各有完全不同的主装置与记忆点（同族不同构）；
- 保留全部真实数据与现有交互，叠加轻量动效，重写页面文案（个人信息保持真实）。

已被用户否决的方向（不再出现）：三页共用冰蓝纸面巨字海报开场、朱砂斜切线 + 章节印章铺满每页。

## 设计原则：同族不同构

全站四个开场装置各自独立：首页＝撕裂纸面巨字海报；搜索＝目录卡；关于＝档案卷宗；友链＝名片与灯。

三页共享的只有底层语法：

| 语法 | 内容 |
|---|---|
| 章节行 | 页首一条等宽字细行：朱砂编号 `01/02/03` + 标签 + 细线 + 右侧读数；沿用现有 PageHero 编号，章节连续 |
| 字体分工 | 中文标题/正文用楷体（`--font-serif`），读数/标签用等宽（`--font-code`），英文点缀少量 Arial 粗体 |
| 色彩 | 全部走现有令牌：墨蓝 `#102434`、朱砂 `#bf4136/#b74c3b`、站点语义色；不新增颜色 |
| 白卡 | 硬投影实心墨蓝（`12px 14px 0` 量级）、1px 细边、微微倾斜（≤1.6deg） |
| 印章 | 朱砂细描边、楷体、轻微旋转；每页仅一枚（查 / 自由 / 留灯） |
| 明暗主题 | 跟随全站现有 light/dark 令牌，不做固定色场景 |

## 统一语法：章节行组件

新增 `src/components/ChapterRule.astro`：

- Props：`no`（编号）、`label`（中文标签）、`en`（英文标签）、`value`（右侧读数，可选）；
- 输出一条 flex 细行：`<span no> <span label> <i 细线> <span value>`，等宽字体、`.14em` 级字距；
- 仅此一个新组件；三页复用，避免三处重复样式漂移。

## 搜索页 · 目录卡（/search/）

### 主装置

页面主角是一张**图书馆目录卡**，替代现 PageHero：

- 白卡 + 1px 细边 + 硬投影墨蓝，整体 `rotate(-0.7deg)`；
- 卡顶一个突出标签页 `INDEX CARD / 目录卡`（墨蓝底白字，等宽小字）；
- 卡内主体即检索字段：楷体大字（clamp(26px, 3.6vw, 44px) 量级），朱砂光标闪烁；右侧放大镜图标沿用；
- 卡内底部：**刻度尺**装饰（repeating-linear-gradient 双层刻度）+ 等宽读数行（`INDEX 37 FILES · CJK+FUZE` 与 `STATUS / READY`）；
- 卡右下一枚圆形「查」章（细描边、旋转）。

### 结果列表

- 每行左侧新增**命中强度刻度**（共 4 格）：中文通道按现有打分归一（`Math.min(4, Math.ceil(score / 2))`，满格为朱砂，其余墨蓝实心）；拉丁通道标题含关键词给 4 格、否则 2 格；
- 关键词朱砂高亮（标题内 `<em>`，等宽部分不处理转义之外的逻辑）；
- 行样式沿用现有 `ed-row` 骨架与宽屏双列网格。

### 交互（全部保留，逻辑不动）

- 中文子串打分 + Fuse 拉丁双通道、索引懒加载、`?q=` 同步、popstate/pageshow 还原、热词推荐、失败重试、noscript 提示；
- **测试保护清单（选择器不得改名）**：`#search-input`、`#search-results`、`#search-status`、`.search-retry`、`.search-noscript`、`.result-row`、`.suggest-btn`；宽屏 `.search-results` 仍为双列 `grid-template-columns`。

### 文案重写

- placeholder：`输入关键词，找回那一行…`
- 状态：`命中 N 篇 · 0.04S`／`没有找到「X」——换个词，或去归档页翻翻`；
- 初始态：`37 篇文章在目录里 · 输入即搜`；
- 热词区：`试试：` 保留。

## 友链页 · 名片与灯（/friend/）

### 页首语

一句楷体标题：`互相留一盏灯。`（「一盏灯」朱砂）+ 等宽小字 `EVERY CARD KEEPS A LIGHT ON`；章节行读数为 `N LIT · EST. 2025`。

### 名片阵列

- **本站名片**：白卡硬投影 `rotate(-1.6deg)`，内容＝站名 ZIYOU（Arial 粗体大字）、站训、`ziyou814.top / EST. 2025`；右上竖排「留灯」印章；数据全部取自 `consts.ts`；
- **朋友名片**：横排卡（头像方块 + 名字楷体 + desc + 域名等宽字），微倾 `0.9deg`，头像用 `ResponsiveImage`（真实 `FRIENDS` 数据，结构不变）；
- **空位名片**：虚线边框、无投影，文案 `你的名片留在这里 · 申请交换 · EXCHANGE`；
- **灯**：每张名片左上一枚圆点——已交换＝朱砂实心 + 微光晕，空位＝空心灰圈；灯是本页唯一循环动效（见动效总则）。

### 交换与留言

- 申请文案重写：`先添加本站，然后在本页留言，按下面格式留下你的信息。审核通过后，你的灯也会亮在这里。`

- Waline 留言区位置不动，标题行改为 `留言 · 交换记录 / WALINE OPEN`。

## 轻量动效总则

- 全部动效一次性入场，优先复用现有 `data-reveal` 机制；
- 目录卡：入场由 `rotate(-2deg)→(-0.7deg)` + 上浮回正；
- 命中刻度：新结果渲染时刻度从 0 填至分值（CSS transition，一次性）；
- 印章（查/自由/留灯）：入场 `scale(1.5)→1` + 透明度 + 落章旋转；
- 名片：三张卡依次 80ms 错位落桌；
- 灯：仅本站与朋友卡有极慢光晕呼吸（≥3s 周期、低幅度）；空位灯静止；
- `prefers-reduced-motion: reduce` 下以上全部禁用（含灯呼吸），无 JS 时静态呈现、无布局依赖。

## 响应式

- ≥1440px：三页沿用 `ed-wrap--wide` 宽栏；搜索结果双列、卷宗登记表双列、名片三列；
- ≤760px：章节行缩字号；目录卡倾斜减至 -1deg、读数行折两行；登记表改单列（dt/dd 同行）；指标 2×2；名片单列纵排、交换区单列；
- 所有卡片旋转与投影量按断点减半，禁止横向溢出。

## 可访问性

- 章节行、刻度尺、灯均为装饰，`aria-hidden="true"`；命中刻度含义由状态行文字承载（`命中 N 篇`）；
- 印章文字进入无障碍树但带 `aria-hidden`（纯装饰）；
- 名片为 `<a>`，名称即链接文本；空位卡不可聚焦；
- 焦点环沿用全局 `:focus-visible`；对比度：朱砂文字仅用于大号楷体或粗体读数，正文保持语义色。
