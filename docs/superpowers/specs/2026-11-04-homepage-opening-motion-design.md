# 首页三幕「朱砂切口」联动动效设计

日期：2026-11-04 ｜ 状态：已获用户批准

## 目标

重做首页开场三幕的运动关系，解决现有封面整体移动、7 条竖切片、冰蓝纸面与文章卡各自独立运动造成的割裂。新的动效以一条朱砂切口为因果主线：红线先切开首屏，封面沿切口撕裂，冰蓝纸面从同一缝隙展开，第二幕标题与文章卡再沿撕裂方向接力落位。

保留现有山路封面、中文主标题、打字文案、冰蓝第二幕视觉、最新文章数据和链接；允许调整首屏排版与首幕运动，不修改首页正文及其他页面。

## 运动时间轴

滚动仍映射到单一 sticky 场景。桌面滚动距离调整为约 `260svh`，移动端约 `230svh`。

| 进度 | 阶段 | 运动 |
|---|---|---|
| `0–0.16` | 首幕蓄势 | 封面轻微推近，首屏维持稳定；切口尚未可见 |
| `0.14–0.28` | 切口出现 | 朱砂线从右上向左下生长，伴随极窄冰蓝高光 |
| `0.26–0.46` | 封面撕裂 | 左上、右下两块封面沿同一对角线错开、旋转并退出；中文标题两行分别随两块封面错位 |
| `0.40–0.62` | 纸面展开 | 冰蓝纸面从切口缝隙扩展为完整第二幕，几何与撕裂方向一致 |
| `0.56–0.74` | 海报汇合 | `BEYOND` 从左侧遮罩推出，`THE CODE` 从右侧滑入，两组标题沿切口汇合；印章随后落入 |
| `0.68–0.86` | 文章卡接力 | 文章卡从右下撕裂块退出的方向进入，翻转到竖版海报并停靠 |
| `0.86–1` | 交付正文 | 第二幕轻微后退，文章卡退出交互区，滚动自然进入正文 |

各阶段允许少量重叠，避免机械排队，但必须先出现切口，再发生撕裂和纸面展开。

## 首幕结构与视觉

- 删除现有 7 条 `.scene-shard` 竖切片及其逐片翻转逻辑。
- 新增两个撕裂层：左上封面块与右下封面块。两层使用同一张山路图片，初始 `clip-path` 在一条对角线处闭合，滚动时用自定义属性打开缝隙。
- 首屏底层保留原始封面作为降级与初始绘制层；撕裂层只在 `has-motion` 下覆盖。
- 中文标题保留现有文案，但两行分别映射到左上、右下撕裂方向，而不是整段一起淡出。
- 首屏边框、底部索引和侧边标签在早期退出，不参与撕裂。
- 首屏只做轻微推近和色深变化，不再做整图上移后由切片补位的旧运动。

## 朱砂切口

- 新增独立的 `.scene-incision` 装饰层，方向与第二幕 `.after-cut` 朱砂斜线一致。
- 切口用 `scaleX` 从一端生长，宽度极窄，带低透明冰蓝高光和少量朱砂辉光；不使用火焰、粒子或循环光效。
- 撕裂开始时切口保持可见；纸面展开后，第二幕红色斜线从同一屏幕轨迹接管，切口层淡出，形成“同一条线贯穿三幕”的视觉因果。
- 移动端保留相同方向，但缩小线宽与位移，不额外增加滚动事件。

## 第二幕衔接

- 冰蓝纸面从撕裂缝隙中以对角 `clip-path` 展开，不再从画面中央做简单水平展开。
- `BEYOND` 与 `THE CODE` 分别使用左侧、右侧遮罩入场，最终在现有海报构图汇合；`CODE` 保持朱砂红。
- 第二幕编辑网格、标尺线与印章沿用现有视觉，但在标题落位后以短延迟出现。
- 文章卡保留当前数据、封面、冷蓝双色调、硬投影、竖版比例和悬停回彩；入场方向与右下撕裂块退出方向一致，最终仍停靠为 `-2deg`。
- 第二幕固定冷蓝调色，不随全站明暗主题改变。

## 数据流与性能

- 继续使用现有 `requestAnimationFrame` 滚动更新函数，只向 `.scene-pin` 写入 CSS 自定义属性；不增加永久动画循环、IntersectionObserver 或第三方动画库。
- 滚动驱动只写 `transform`、`opacity`、`clip-path` 和 `filter` 中已由现有代码使用的模糊量；撕裂块、纸面、标题、文章卡分别读取自己的变量。
- 图片层从 7 张切片减少为 2 张撕裂层；不新增图片资源。
- 所有动画响应同一滚动进度，快速滚动和反向滚动不维护额外内部状态。
- 移动端复用同一进度映射，位移、旋转与模糊量降低，避免小屏过曝或抖动。

## 响应式

- 桌面保持首屏全幅封面、第二幕左标题右文章卡的构图。
- `≤760px` 保持相同切口方向，但首屏标题按视口缩放，第二幕继续使用上方标题、下方文章卡的纵向海报。
- 所有撕裂块允许在 sticky 容器内裁切，但不得扩大页面横向滚动区域。
- 窄屏缩短每段运动距离，并减少切口辉光与文章卡翻转角。

## 降级与可访问性

- `prefers-reduced-motion: reduce` 下保持当前静态首屏，不新增运动；第二幕装饰继续隐藏。
- 无 JavaScript 时沿用现有首屏降级，撕裂层、第二幕和文章卡不遮挡内容。
- 撕裂层、切口和第二幕装饰均使用 `aria-hidden="true"`；页面主标题结构不变。
- 最新文章链接仍只在文章卡可交互阶段进入 Tab 顺序，`inert` 与 `aria-hidden` 同步切换。
- 首屏与第二幕的文字对比度不因动画中间态低于可阅读要求；装饰辉光不得覆盖链接。

## 验收

1. `npm run build` 在 `astro/` 下通过。
2. Playwright 在 `1440×1000` 与 `390×844` 检查 `0%、20%、40%、60%、80%、100%` 六个关键帧：切口、撕裂、纸面、标题和文章卡按时间轴出现，无错位遮挡。
3. 对比 `0.26` 与 `0.46` 帧，确认朱砂切口与封面撕裂、第二幕红线方向一致。
4. 检查文章卡点击目标、悬停回彩、`inert` 与 `aria-hidden` 行为保持正确。
5. 桌面与手机均无横向溢出，移动端标题和文章卡完整可读。
6. 减少动态效果模式下无新增滚动动画，首屏与正文可正常阅读。
7. 现有 `npm run test:ui` 17 项测试全部通过。
