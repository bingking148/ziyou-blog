# 首页第二幕「冰蓝纸上未来」设计

日期：2026-11-04 ｜ 状态：已获用户批准

## 目标

保留首页现有三幕滚动叙事，整体重构第二幕的视觉，解决暗色描边字与椭圆轨道缺乏冲击力的问题。第二幕采用杂志海报语言，以**冷蓝色相统一、明暗与材质形成反差、朱砂小面积点睛**为原则，避免首屏蓝色影像切换到暖米白造成的割裂。

## 范围

只修改 `astro/src/pages/index.astro` 中第二幕的 HTML、CSS 和现有滚动更新函数里的必要变量。保留：

- 首屏封面、中文主标题、打字文案与文章索引；
- 三幕滚动轨道、触发区间和最新文章数据来源；
- 最新文章链接及键盘可访问性；
- 首页正文与其他页面。

不新增依赖、字体或内容字段，不修改 Hugo 备份站。

## 色彩与材质

| 用途 | 颜色 / 处理 |
|---|---|
| 首屏与转场底层 | 沿用深海蓝 `#0a1420` |
| 第二幕纸面 | 冰蓝渐变 `#d4e4eb → #edf4f6 → #cbdfe8`，右上加入冰白径向光 |
| 主标题与硬投影 | 深墨蓝 `#102434` |
| `CODE`、切线、印章 | 朱砂 `#b74c3b` |
| 编辑网格 | 低透明度墨蓝细线，叠加极轻纸面颗粒 |
| 文章照片 | 默认降低饱和度并叠蓝调；悬停恢复全彩 |

纸面必须是冰蓝白而非暖米白。视觉顺序为深海蓝影像 → 冰蓝纸面 → 冰白正文，通过相同色相和渐进明度衔接三幕。

## 第二幕构图

### 标题

- 删除原来的低对比空心描边字。
- `BEYOND` 位于左上，使用 Arial / Helvetica 超粗无衬线、大字号、紧字距。
- `THE CODE` 换行并缩进，使用 Georgia 斜体衬线形成字体反差；`CODE` 使用朱砂红。
- 标题保持装饰性，仍在 `aria-hidden="true"` 的第二幕容器内，不改变页面主标题结构。
- 中文短句改为「代码之外，仍有世界。」，配两行小号英文编辑注释，位于标题左下方。

### 线条与编辑元素

- 删除两条椭圆轨道。
- 使用低对比编辑网格、水平双标尺线、右侧竖向参考线和两条斜切线。
- 朱砂斜线负责把视线从标题引向文章卡，其余线条使用墨蓝。
- 标题与文章卡之间放置圆形 `02` 印章，使用朱砂描边并轻微旋转。
- 第二幕的进度条、侧边文字和滚动提示切换为墨蓝，避免冰蓝背景上仍使用白色而失读。

### 最新文章卡

- 保留现有 `latest` 数据、封面、短标题、`postUrl(latest)` 和进入文章提示。
- 卡片改为右侧竖向海报比例，最终旋转约 `-2deg`，使用无模糊的深墨蓝错位硬投影。
- 封面默认冷蓝双色调；悬停时照片恢复全彩、卡片轻微抬升，箭头沿用现有位移反馈。
- 卡片只改变视觉，不增加额外链接或交互入口。

## 动效与数据流

沿用现有 `requestAnimationFrame` 滚动映射，不新增永久动画循环：

1. `split` 阶段继续让首屏胶片切片分开并淡出。
2. `reveal` 阶段让冰蓝纸面从中央向左右展开，透明度同步到位；标题与线条只有小幅分层位移，不独立循环。
3. `arrive` 阶段继续驱动最新文章卡入场，最终落到 `-2deg`。
4. `exit` 阶段保持现有离场与正文衔接。

必要的展开量、标题位移和线条位移通过现有 `.scene-pin` CSS 自定义属性传递。只修改 `transform`、`opacity` 与 `clip-path`，不引入内容数据流或新的运行时状态。

## 响应式

- 桌面保持左侧巨字、右侧竖向文章卡的非对称海报构图。
- `≤760px` 改为上方标题、下方文章卡的纵向海报；标题按视口宽度缩放，卡片宽度约为 `68vw`。
- 移动端隐藏英文编辑注释与圆形印章，减少线条数量，保留中文短句和朱砂 `CODE`。
- 所有装饰允许在容器内裁切，但不得扩大页面横向滚动区域；文章标题与进入链接必须完整可读。

## 降级与可访问性

- 装饰 SVG、网格、印章继续使用 `aria-hidden="true"`。
- 最新文章仍是一个可聚焦链接，现有 `inert` 与 `aria-hidden` 的滚动切换逻辑保持有效。
- `prefers-reduced-motion: reduce` 下保持当前无滚动动画的静态首屏，不新增运动。
- 无 JavaScript 时沿用现有首屏降级，第二幕装饰不遮挡首屏内容。
- 第二幕使用固定冷蓝调色，不随全站明暗主题改变。

## 验收

1. `npm run build` 在 `astro/` 下通过。
2. Playwright 在 `1440×1000` 与 `390×844` 检查第二幕稳定状态：标题、线条、印章、文章卡层级正确，无横向溢出。
3. 检查首屏、第二幕与正文交界，色彩从深海蓝到冰蓝白连续，不出现暖白跳变。
4. 最新文章链接只在可交互阶段进入 Tab 顺序，点击目标与改造前一致。
5. 桌面悬停时封面恢复全彩；移动端不依赖悬停即可阅读。
6. 减少动态效果模式下不出现新增位移或展开动画，首屏与正文可正常阅读。
