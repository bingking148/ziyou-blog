# 首页「导演式向下按键」设计

日期：2026-11-04 ｜ 状态：已获用户批准

## 目标

在首页首屏增加一个向下按键。点击后以一镜到底的方式滚动到第二幕完整落位，完整展示现有「朱砂切口」三幕动画。节奏必须优雅且可控：不能快到看不清切口与撕裂，也不能慢到让人等待。

## 范围

只修改 `astro/src/pages/index.astro`：

- 改造现有 `.scene-scroll` 右下角入口为圆形向下按键；
- 在现有三幕滚动脚本中新增点击播放与取消逻辑；
- 不新增依赖、不改文章数据、不改正文与其他页面。

## 按钮视觉与状态

- 桌面为约 `58px` 圆形按键，手机为约 `48px`；中心为向下箭头，下方保留微型 `PLAY OPENING` 标签。
- 视觉沿用首幕冰蓝细描边与白色箭头，悬停时箭头下移、外圈微亮，不引入新的颜色系统。
- 按钮只在首幕可点击；滚动进度超过 `0.18` 后淡出并设置 `inert`，避免与第二幕文章卡争夺焦点。
- 播放中按钮淡出并标记 `aria-disabled="true"`，结束后停留在第二幕，不自动进入正文。
- 手机位置避开底部第一篇文章索引和进度条，不允许造成横向溢出。

## 播放编排

- 点击目标为三幕进度 `0.86`：朱砂切口、封面撕裂、冰蓝纸面、`BEYOND THE CODE`、印章与最新文章卡全部完整落位。
- 基础时长：桌面 `3800ms`，`≤760px` 手机 `3400ms`。
- 若用户从首幕中途点击，按剩余进度与总目标进度的比例缩短时长，但最短不低于基础时长的 `55%`。
- 使用缓入缓出 cubic easing，逐帧写入滚动位置，不使用浏览器自动平滑滚动。
- 时间感受大致为：
  - `0–0.6s`：首幕蓄势与红线出现；
  - `0.6–1.8s`：封面沿切口撕裂；
  - `1.5–2.4s`：冰蓝纸面展开；
  - `2.0–2.7s`：海报标题汇合；
  - `2.6–3.3s`：文章卡落位；
  - 最后约 `0.5s`：柔和收束并停在第二幕。

## 控制权与实现

- 仅当页面已有 `.has-motion` 且未开启 `prefers-reduced-motion: reduce` 时拦截点击并播放；否则保留现有 `#journal` 链接跳转。
- 播放使用单个 `requestAnimationFrame` 循环：
  1. 记录起始滚动位置与目标位置；
  2. 播放期间将文档滚动行为临时设为 `auto`；
  3. 每帧按 easing 计算滚动位置并调用 `scrollTo({ behavior: 'auto' })`；
  4. 完成后恢复滚动行为、移除播放状态。
- 以下情况立即取消播放并交还控制权：
  - 用户滚轮或触摸；
  - 方向键、Space、PageUp、PageDown、Home、End；
  - 窗口 resize；
  - 页面进入后台。
- 取消时不回滚位置，也不锁定滚动；用户从当前画面继续手动滚动。
- 现有三幕更新函数继续由滚动事件驱动，播放循环只改变滚动位置，不重复维护动画状态。

## 可访问性与降级

- 按钮保留链接语义与可见焦点环；键盘 Enter 可触发播放。
- `aria-label` 明确为「播放开场动画并进入第二幕」。
- 播放中设置 `aria-disabled="true"` 与 `inert`，避免重复触发。
- 减少动态效果或无 JavaScript 时，点击仍跳转到 `#journal`，不出现额外动画。
- 播放不得改变最新文章卡原有的 `inert` 与 `aria-hidden` 逻辑。

## 验收

1. `npm run build` 通过。
2. Playwright 桌面与手机点击按钮：
   - 最终三幕进度为 `0.86 ± 0.01`；
   - 中途采样可见切口、撕裂、纸面、标题与文章卡依次出现；
   - 播放结束后页面无横向溢出、无页面错误。
3. 播放中触发滚轮或按键能立即取消，后续手动滚动正常。
4. 按钮在进度 `0.18` 后不可交互；播放中不可重复触发。
5. 减少动态效果模式下点击按钮跳转到 `#journal`，无导演式滚动。
6. 现有 `npm run test:ui` 17 项测试全部通过。
